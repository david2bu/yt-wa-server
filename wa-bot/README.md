# מערכת שליחות לקבוצות וואטסאפ

הלקוחות שולחים לבוט בוואטסאפ את מה שהם רוצים לפרסם. אתה מנהל הכל מאתר על הדומיין שלך:
רואים מה כל אחד שלח, קובעים מתי זה יוצא ולאילו קבוצות, והבוט שולח בזמן.

## איך זה עובד

1. **לקוח שולח** לבוט תמונה, סרטון, קובץ או טקסט. כמה הודעות ברצף נחשבות פרסום אחד.
2. **אם ללקוח יש משבצות קבועות** (למשל "ראשון 10:00 לקבוצות א׳ ו-ב׳"), הפרסום נכנס לבד למשבצת הפנויה הבאה,
   והלקוח מקבל הודעה: "יפורסם ביום ראשון 26/10 בשעה 10:00".
3. **אם אין לו משבצות**, הפרסום מחכה באתר בלשונית "הגשות", ואתה קובע תאריך, שעה וקבוצות.
4. **בזמן שנקבע** הבוט שולח לקבוצות, והלקוח מקבל "📢 הפרסום שלך יצא".

לקוח יכול לכתוב לבוט *סטטוס* (מה מתוזמן לו) או *ביטול* (מבטל את הפרסום האחרון).
מספר שלא רשום כלקוח לא יכול לפרסם. הפנייה שלו מופיעה באתר עם כפתור "הוסף כלקוח".

## האתר

| לשונית | מה יש בה |
|---|---|
| **לוח** | סיכום: ממתינים לתזמון, מתוזמנים, תקלות, ומה יוצא ביומיים הקרובים |
| **הגשות** | כל מה שנשלח, עם תצוגה של התמונות והסרטונים. תזמון, שליחה מיידית, ביטול ומחיקה. סינון לפי לקוח ומצב |
| **יומן** | כל השליחות לפי ימים. אפשר לשנות מועד או לבטל |
| **לקוחות** | הוספה ועריכה, משבצות קבועות לכל לקוח, השבתה, ופניות ממספרים לא רשומים |
| **פרסום חדש** | העלאת קבצים וטקסט ישירות מהאתר, בשבילך או בשביל לקוח |
| **חיבור** | מצב החיבור לוואטסאפ, ה-QR לסריקה ורשימת הקבוצות |

## התקנה על השרת (פקודה אחת)

על שרת Linux, כמו DigitalOcean, מריצים פקודה אחת. היא מתקינה הכל ומחברת את הבוט לכתובת עם HTTPS.
אם כבר רץ על השרת אתר עם nginx, הבוט נוסף לצידו בלי לפגוע בו.

```bash
curl -fsSL https://raw.githubusercontent.com/david2bu/yt-wa-server/main/wa-bot/install.sh | sudo bash -s bot.judit.live
```

לפני כן צריך רשומת A, למשל `bot.judit.live`, שמצביעה על ה-IP של השרת. עדכון גרסה: מריצים את אותה פקודה שוב.

## התקנה ידנית

צריך שרת עם Docker, ודומיין שמצביע עליו.

**1. להפנות את הדומיין לשרת.** אצל ספק הדומיין יוצרים רשומת **A** (למשל `bot.example.com`) שמצביעה על כתובת ה-IP הציבורית של השרת.
אם השרת בבית, צריך גם להפנות בראוטר את פורטים **80** ו-**443** אל השרת (Port Forwarding).

**2. להתקין ולהפעיל:**
```bash
git clone https://github.com/david2bu/yt-wa-server.git
cd yt-wa-server/wa-bot
cp .env.example .env
nano .env                 # למלא DOMAIN, ADMIN_PASSWORD, OWNER_PHONES
docker compose up -d --build
```
תעודת ה-HTTPS נוצרת ומתחדשת אוטומטית (Caddy).

**3. לחבר את הבוט לוואטסאפ:** נכנסים ל-`https://<הדומיין>`, ובלשונית **חיבור** סורקים את ה-QR מהטלפון של הבוט
(וואטסאפ ← מכשירים מקושרים ← קישור מכשיר). החיבור נשמר בתיקייה `data/`, כך שלא צריך לסרוק שוב.

**4. להוסיף את הבוט לקבוצות** כמו כל משתתף, וללחוץ "רענון מוואטסאפ" בלשונית **חיבור**.

**5. להוסיף לקוחות** בלשונית **לקוחות** ולהגדיר להם משבצות.

### פקודות שימושיות
```bash
docker compose logs -f wa-bot        # לוגים
docker compose restart wa-bot        # הפעלה מחדש
git pull && docker compose up -d --build   # עדכון גרסה
```

גיבוי: כל המידע (חיבור, לקוחות, תזמונים, קבצים) נמצא בתיקייה `data/`.

## יציבות

- **חיבור שנופל:** הבוט מתחבר מחדש אוטומטית. אם הוא לא מצליח 10 דקות, התהליך כולו מופעל מחדש.
- **שום דבר לא הולך לאיבוד:** כל תזמון נשמר במסד נתונים. אם השרת היה כבוי בזמן שליחה, היא יוצאת מיד כשהוא חוזר.
- **שליחה שנכשלה** מנוסה שוב עד 6 פעמים. אם עדיין נכשלה, היא מסומנת באדום באתר עם כפתור "נסה שוב".
- **מניעת כפילויות:** אם פרסום של כמה פריטים נקטע באמצע, ההמשך יוצא מהנקודה שבה נעצר, בלי לשלוח שוב.
- **מניעת חסימה:** יש השהייה אקראית של כמה שניות בין קבוצות.
- **בדיקת זמינות:** `https://<הדומיין>/health` מחזיר 200 כשהבוט מחובר. אפשר לחבר אותו ל-UptimeRobot כדי לקבל התראה.

> החיבור לוואטסאפ לא רשמי (כמו WhatsApp Web). מומלץ מספר ייעודי לבוט.

## פקודות בוואטסאפ (למנהל)

`!סטטוס`, `!קבוצות`, `!עזרה`. פקודות אישיות נוספות מוסיפים ב-`src/commands/personal.js`.
