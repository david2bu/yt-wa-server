# בוט וואטסאפ להפצת קבצים לקבוצות

משתמשים מאושרים שולחים לבוט קובץ, תמונה, סרטון, שמע או טקסט. הבוט שואל לאיזו קבוצה לשלוח ומפרסם שם.
כל משתמש רואה רק את הקבוצות שהמנהל אישר לו.

## מה עושה אותו יציב

| בעיה | הפתרון בבוט |
|---|---|
| החיבור נופל | חיבור מחדש אוטומטי עם המתנה שגדלה בהדרגה (עד דקה), בלי סוף |
| נתקע ולא חוזר | Watchdog: אחרי 10 דקות בלי חיבור התהליך מופעל מחדש (Docker/pm2 מרימים אותו) |
| הודעות הולכות לאיבוד | כל הודעה נשמרת קודם בתור במסד נתונים (SQLite). היא נשלחת כשיש חיבור, וכשל מנוסה שוב עד 6 פעמים |
| התנתקות מהטלפון | החיבור הישן נמחק אוטומטית ומוצג QR חדש בדף הסטטוס |
| "ממתין להודעה זו" אצל המקבלים | ההודעות שנשלחו נשמרות כדי ש-WhatsApp יוכל לבקש אותן שוב |
| חסימה | השהייה אקראית של 3-7 שניות בין פרסומים, בלי "מחובר" קבוע ובלי סנכרון היסטוריה |
| שני עותקים רצים במקביל | מזוהה (קוד 440), והבוט מחכה במקום להילחם על החיבור |

> החיבור הוא לא רשמי (Baileys, כמו WhatsApp Web). מומלץ מספר ייעודי לבוט ולא המספר האישי.

## התקנה על השרת (Docker, מומלץ)

```bash
git clone https://github.com/david2bu/yt-wa-server.git
cd yt-wa-server/wa-bot
cp .env.example .env
nano .env            # למלא OWNER_PHONES (המספר שלך) ו-WEB_TOKEN (סיסמה)
docker compose up -d --build
docker compose logs -f
```

לחבר את הבוט: לפתוח בדפדפן `http://<כתובת-השרת>:3000/qr?token=<WEB_TOKEN>`,
ואז בטלפון של הבוט: **וואטסאפ ← מכשירים מקושרים ← קישור מכשיר**, ולסרוק.
החיבור נשמר בתיקייה `data/`, כך שאחרי הפעלה מחדש לא צריך לסרוק שוב.

### בלי Docker (pm2)

צריך Node.js 22.13 ומעלה.

```bash
npm ci --omit=dev
npm i -g pm2
pm2 start ecosystem.config.cjs
pm2 save && pm2 startup     # עלייה אוטומטית אחרי ריסטארט של השרת
```

## שימוש

### מנהל (מהמספר שב-OWNER_PHONES, בצ'אט פרטי עם הבוט)

| פקודה | מה עושה |
|---|---|
| `!קבוצות` | רשימת הקבוצות של הבוט, ממוספרות |
| `!אשר 0501234567 1,3` | מאשר משתמש לקבוצות 1 ו-3 (או `הכל`) |
| `!הסר 0501234567 2` | מסיר הרשאה לקבוצה 2. בלי מספרים המשתמש נמחק |
| `!משתמשים` | מי מורשה ולאן |
| `!סטטוס` | מצב החיבור והתור |
| `!נסה-שוב` | שולח שוב הודעות שנכשלו |
| `!עזרה` | כל הפקודות |

כשמישהו לא מורשה כותב לבוט, מקבלים הודעה עם הפקודה המוכנה לאישור שלו.
אם הבוט רץ על המספר שלך, אפשר לכתוב את הפקודות בצ'אט "הודעה לעצמי".

### משתמש

1. שולחים לבוט קבצים או טקסט (אפשר כמה ביחד, ותישאל שאלה אחת).
2. הבוט מציג את הקבוצות המותרות. עונים `1`, `1,3`, `2-4` או `הכל`.
3. מקבלים עדכון כשנשלח. `ביטול` מבטל.

לבוט להוסיף ידנית לקבוצות (כמו כל משתתף). אחרי זה מריצים `!קבוצות`.

## פקודות אישיות

כדי להוסיף פקודות לשימוש שלך בלבד, מוסיפים אותן ב-`src/commands/personal.js`. הן מופיעות אוטומטית ב-`!עזרה`.
