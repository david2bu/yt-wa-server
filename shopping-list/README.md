# רשימת קניות לבית

אפליקציה עצמאית (Flask + SQLite), לא קשורה לשרת הוואטסאפ שבתיקייה הראשית.

- **מי מזמין** — בוחרים שם מהרשימה (נשמר בדפדפן), בלי התחברות.
- **דחוף לשבת / שוטף** — כל פריט נכנס לאחת משתי הרשימות.
- **הצעות** — מוצרים שנקנו פעמיים ומעלה או שסומנו ⭐ קבועים, עם "הגיע הזמן" לפי המרווח הרגיל בין קניות.
- **בנה רשימה לשבת** — כפתור שמציע את מה שהוזמן כ"לשבת" ב-8 השבתות האחרונות, עם סימון מראש של מה שחוזר ברוב השבתות.
- **מחירים** — מחיר ליחידה למוצרים, והערכת מחיר לקנייה (לשבת / שוטף / סה"כ).

## הרצה מקומית

    pip install -r requirements.txt
    python app.py        # http://localhost:8080

## פריסה ב-Railway

שירות חדש מאותו ריפו, עם **Root Directory = `shopping-list`**.
הנתונים נשמרים ב-`DATA_DIR` (ברירת מחדל `./data`) — כדי שלא יימחקו בכל deploy,
מחברים Volume ב-`/data` ומגדירים `DATA_DIR=/data`.
