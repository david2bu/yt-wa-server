## רשימת קניות לבית — `/shop`

רשימת קניות משותפת לכל המשפחה, בלי התחברות.

- **מי מזמין** — בוחרים שם מהרשימה (נשמר בדפדפן), כל פריט מציג מי הזמין ומי קנה.
- **דחוף לשבת / שוטף** — כל פריט נכנס לאחת משתי הרשימות, אפשר להחליף בלחיצה.
- **הצעות** — מוצרים שנקנו פעמיים ומעלה או שסומנו ⭐ קבועים, עם סימון "הגיע הזמן" לפי המרווח הרגיל בין קניות.
- **מחירים** — בלשונית "מוצרים ומחירים" מגדירים מחיר ליחידה, ולמטה מוצגת הערכת מחיר (לשבת / שוטף / סה"כ).
- **סיימתי קנייה** — מעביר את מה שסומן כנקנה להיסטוריה (שממנה נבנות ההצעות).

הנתונים נשמרים ב-SQLite בתיקייה `DATA_DIR` (ברירת מחדל `./data`).
**חשוב ב-Railway:** מערכת הקבצים מתאפסת בכל deploy — צריך לחבר Volume (למשל ב-`/data`) ולהגדיר משתנה סביבה `DATA_DIR=/data`.
